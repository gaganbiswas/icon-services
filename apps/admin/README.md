# @icon/admin

Staff admin panel: Vite + React + TanStack Router (file-based routes in
`src/routes`, ADR 0008). Used by Super Admin, Branch Admin/Manager, Reception,
Technician, Accounts, Delivery Staff and Auditor roles.

- `bun run dev` — http://localhost:5173
- `bun run build` — static build in `dist/`
- `bun run test` — Vitest + Testing Library

`src/routeTree.gen.ts` is generated by the TanStack Router plugin on `dev`,
`build` and `test`; it is committed so type-checking works without a build.
Do not edit it by hand. This app holds no secrets; all authorization is
enforced by the API.
