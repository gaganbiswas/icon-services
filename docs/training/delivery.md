# Delivery staff

- **Delivery** tab on a ready job.
- Pick-up / on-site return: fill the recipient's name and who they are (customer, family member …; others need a
  note on how they are authorized), tick **every** item that goes back (device and all accessories received), tick
  the hand-over checklist, choose proof (signed challan or photo) → **Complete hand-over**.
- Home delivery: **Dispatch** with the address first (prints a challan number). If nobody is home, **Delivery
  failed** with a reason; the job returns to *Ready for delivery*.
- If money is still due, only a manager can approve the hand-over.
- **Print challan** — it is a hand-over document, not an invoice or payment receipt.
