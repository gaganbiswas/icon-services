# Staff quick guides

Short task guides for each role in the staff panel. They describe release one; screens may still change during UAT.

- [Reception](reception.md)
- [Technician](technician.md)
- [Accounts](accounts.md)
- [Delivery staff](delivery.md)
- [Manager / administrator](manager-admin.md)

General: sign in with your e-mail and password (and the 6-digit code from your authenticator app if two-step
sign-in is on). The panel only shows what your role may do; the server checks every action again. Everything you
change is recorded in the audit log with your name and the time.
