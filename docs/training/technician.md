# Technician

1. **My jobs** lists the jobs assigned to you.
2. Open a job → **Work** tab:
   - **Status**: move the job forward (Diagnosis → Estimate preparation …). Some moves need a reason.
   - **Diagnosis**: symptom, findings, recommended work. *Internal notes* are never shown to customers.
   - **Work log**: choose *Customer can see* only for plain, polite updates.
3. **Estimates** tab: add part / labour lines → **Save draft**. A manager sends it to the customer. Repair work
   cannot start until the customer approves (the system blocks it).
4. **Parts** tab: reserve parts, record parts used and returned; stock cannot go below zero.
5. When repaired: status **Quality check** → **Repair completion**: write the summary and tick every QC item →
   **Complete repair** → **Ready for delivery** with a short customer message.
