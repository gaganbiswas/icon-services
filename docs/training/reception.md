# Reception

## Register a repair (New job)
1. **New job** → search the customer by name, mobile number or customer code. Not found? **New customer** →
   name, mobile with country code, consent for WhatsApp / e-mail updates → **Save and continue**.
2. Pick the device or add a new one (category, brand, model, serial number). A warning appears if the serial
   number already exists on another record — check it is not a duplicate.
3. Write the complaint in the customer's own words, list accessories received and visible condition, add photos.
4. Choose warranty status (if unsure: *Warranty not yet verified*) and service mode (centre / on-site address).
5. **Review** → **Register job**. If the network fails, press it again — it never creates two jobs.
6. **Print receipt** (A4 or 80 mm) and give it to the customer.

## Daily
- Search by job number, customer, mobile or serial number from **Jobs**.
- You cannot change job status or prices; ask the manager or technician.
